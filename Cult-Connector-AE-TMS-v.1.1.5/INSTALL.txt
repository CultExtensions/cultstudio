Cult Connector — Adobe After Effects ↔ TMS
==========================================

ScriptUI panel for After Effects: send compositions and screenshots to your
translation management system (Crowdin or Phrase TMS), translate with full visual
context, and import localized comps without leaving your timeline.

This bundle is a ZIP install for macOS and Windows. For the full guide, open
README.html in any browser. For Phrase TMS workflows, troubleshooting, and
Verified-program technical details, see README.html and TECHNICAL.html.

REQUIREMENTS
------------
• Adobe After Effects (a recent year build is recommended)
• TMS access (Crowdin or Phrase TMS) and a Cult Extensions account (trial
  available): https://cultextensions.com/
• One computer per Cult seat (device binding)
• Network permission for the panel — see “Before first launch” below


BEFORE FIRST LAUNCH — AFTER EFFECTS SCRIPTING
----------------------------------------------
Most Cult Connector features need network access (TMS API, Cult Extensions
auth). Without this, the panel may appear blank or fail silently.

1. Open After Effects → Preferences (macOS) or Edit → Preferences (Windows) →
   Scripting & Expressions.

2. Enable “Allow Scripts to Write Files and Access Network”.

3. Quit After Effects completely and reopen so the setting applies everywhere.


INSTALL — macOS
---------------
1. Open After Effects.

2. Go to File → Scripts → Install Script UI Panel…

3. Select “Cult Connector (AE ↔ TMS).jsxbin”.

4. Restart After Effects.

5. Open Window → Cult Connector (AE ↔ TMS) (the menu entry matches the
   script file name).

If you install a new After Effects version later, you may need to run
“Install Script UI Panel…” again for that version.


INSTALL — WINDOWS
-----------------
1. Open After Effects.

2. Go to File → Scripts → Install Script UI Panel…

3. Select “Cult Connector (AE ↔ TMS).jsxbin”.

4. Restart After Effects.

5. Open Window → Cult Connector (AE ↔ TMS) (the menu entry matches the
   script file name).

If Windows blocks the install prompt, run After Effects as Administrator once,
install the panel, then reopen normally.


PHRASE TMS (SUMMARY)
---------------------
Full steps are in README.html. In short:

1. Choose Phrase in the panel → OK → Allow in the browser tab Cult Connector opens.
2. Select your Phrase project and target languages.
3. Send Selected Compositions (strings + timeline screenshots → Job Preview in Phrase).
4. Translate in Phrase; Import Selected in AE when ready.

Troubleshooting and technical/API details: README.html and TECHNICAL.html.
