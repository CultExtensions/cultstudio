Cult Connector — Adobe After Effects ↔ TMS (Crowdin & Phrase)
=============================================================

ScriptUI panel for After Effects: send compositions and screenshots to your
translation management system (TMS), translate with visual context, and import
localized comps without leaving your timeline.

Supported TMS in this build:
  • Crowdin (Teams and Enterprise)
  • Phrase TMS (EU cloud: cloud.memsource.com)

This bundle is a ZIP install for macOS and Windows. For the formatted guide,
open README.html in any browser.

REQUIREMENTS
------------
• Adobe After Effects (recent year build recommended)
• Cult Extensions account with a workspace seat (trial available):
  https://cultextensions.com/
• Access to Crowdin and/or Phrase TMS (account on your TMS allowlist)
• Network permission for the panel — see “Before first launch” below


BEFORE FIRST LAUNCH — AFTER EFFECTS SCRIPTING
----------------------------------------------
Most features need network access (Cult Extensions auth + TMS API).

1. After Effects → Preferences (macOS) or Edit → Preferences (Windows) →
   Scripting & Expressions.

2. Enable “Allow Scripts to Write Files and Access Network”.

3. Quit After Effects completely and reopen.


INSTALL — macOS / Windows
-------------------------
1. File → Scripts → Install Script UI Panel…

2. Select “Cult Connector (AE ↔ TMS).jsxbin” (or the .jsx if you develop locally).

3. Restart After Effects.

4. Window → Cult Connector (AE ↔ TMS).


FIRST CONNECTION (no license.json)
----------------------------------
1. Open the panel → Choose TMS → Crowdin or Phrase.

2. Sign in via the browser (OAuth). Your Cult Studio workspace email must be
   on the allowlist for your license.

3. Pick a project and use Send / Import as usual.


USING CULT CONNECTOR (QUICK)
----------------------------
1. Composition tab: select comps and languages → Send Selected Compositions.

2. Use Snapshot Marker (▲) on tricky motion for exact screenshot frames.

3. Phrase: after screenshots, the server publishes a job with Live Preview.

4. Crowdin: optional Content Segmentation; Pseudo Translation for layout tests.

5. Import Selected when translations are ready in your TMS.
