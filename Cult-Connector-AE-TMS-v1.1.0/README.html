Cult Connector

ScriptUI panel for Adobe After Effects. Connect to Crowdin or Phrase TMS, send strings and timeline screenshots with visual context, and import localized compositions.

Crowdin Teams & Enterprise Phrase TMS macOS & Windows

Requirements

  • Adobe After Effects
  • Cult Extensions workspace seat (trial available)
  • Crowdin and/or Phrase TMS account on your workspace allowlist
  • AE scripting: Allow Scripts to Write Files and Access Network

Install

  1. File → Scripts → Install Script UI Panel…
  2. Select Cult Connector (AE ↔ TMS).jsxbin
  3. Restart After Effects
  4. Window → Cult Connector (AE ↔ TMS)

No license.json file — sign in with OAuth; Cult Extensions binds your Mac on first login.

Choose your TMS

  1. Open the panel → dropdown: Crowdin or Phrase.
  2. Crowdin: connect Teams or Enterprise → pick project.
  3. Phrase: browser login → pick Phrase project.

Workflow

  1. Send Selected Compositions — exports text + timeline screenshots.
  2. Snapshot Marker (▲) — pin the best frame for animated/typewriter text.
  3. Translate in your TMS (Phrase: optional AI Translation in the panel).
  4. Import Selected — new comps per language (CompName_lang).
