Cult Connector

ScriptUI panel for Adobe After Effects. Send compositions and screenshots to your TMS (Crowdin or Phrase TMS), translate with full visual context, and import localized comps—without leaving your timeline.

Requirements

  • Adobe After Effects (recent year build recommended)
  • TMS access — Crowdin (Teams or Enterprise) and/or Phrase TMS — plus a Cult Extensions account (trial available)
  • Network permission for the panel (see below)
  • For Phrase: a Registered OAuth app redirect URI pointed at Cult Extensions (managed by your administrator; see Technical documentation)

Before first launch — After Effects scripting

  1. Open After Effects → Preferences (macOS) or Edit → Preferences (Windows) → Scripting & Expressions.
  2. Enable Allow Scripts to Write Files and Access Network.
  3. Quit After Effects completely and reopen so the setting applies everywhere.

The panel needs network access (TMS API via login.cultextensions.com, Cult Extensions auth). Without this, the panel may appear blank or fail silently.

Install on macOS

  1. Open After Effects.
  2. Go to File → Scripts → Install Script UI Panel…
  3. Select Cult Connector (AE ↔ TMS).jsxbin.
  4. Restart After Effects.
  5. Open Window → Cult Connector (AE ↔ TMS).

New AE versions may require installing the panel again for that version.

Install on Windows

  1. Open After Effects.
  2. Go to File → Scripts → Install Script UI Panel…
  3. Select Cult Connector (AE ↔ TMS).jsxbin.
  4. Restart After Effects.
  5. Open Window → Cult Connector (AE ↔ TMS).

If Windows blocks the install, run After Effects as Administrator once, install the panel, then reopen normally.

First-time setup (all TMS providers)

  1. Open the panel → Settings tab if you need license or workspace options.
  2. On first run, choose Crowdin or Phrase from the TMS menu and click OK.
  3. Complete sign-in in the browser when the panel opens it (click Allow on the authorization page).
  4. Select your TMS project and target languages.
  5. Use the Composition tab to export and import.

In-panel Readme (Settings tab) shows version, copyright, and data security summary.

Phrase TMS — configuration & workflow

Cult Connector connects After Effects to Phrase TMS through Cult Extensions. Translators work in Phrase with visual context (timeline screenshots in the Job Preview Package).

Prerequisites

  • Phrase TMS account with access to at least one project (and target languages configured).
  • Cult Extensions license with your Phrase login email on the workspace allowlist (Cult Studio dashboard).
  • Phrase Registered OAuth App (TMS → Settings → Integrations) with redirect URI https://login.cultextensions.com/integrations/phrase/oauth/callback. Browser login uses cloud.memsource.com/web/oauth/authorize (EU) or us.cloud.memsource.com/web (US) — not the Platform dashboard card alone.

Connect Phrase TMS

  1. In the onboarding screen, choose Phrase → OK.
  2. Your browser opens the Phrase authorization page. Sign in and click Allow.
  3. Return to After Effects — the panel shows “Connected” and loads your Phrase projects.
  4. Select a project and confirm target languages appear in the Composition tab.

Complete Allow in the browser tab opened by Cult Connector (on cloud.memsource.com or your US TMS host). Opening Phrase from the web dashboard alone does not connect the panel.

If the panel later shows not connected or API errors, use Disconnect then connect again (Phrase → OK → Allow). Cult stores your Phrase session on the server for this computer only.

Export compositions to Phrase (with visual context)

  1. Select one or more compositions in the project panel.
  2. Choose target language(s) in the panel.
  3. Optional: enable Content segmentation if long text layers should be split into multiple segments in Phrase (WebXML segmentation).
  4. Click Send Selected Compositions (or your export action). The panel will:
    • Upload text layers as WebXML source content.
    • Capture timeline screenshots (snapshot markers help lock frames on motion graphics).
    • Publish a Job Preview Package to Phrase so linguists see frames in context.
  5. In Phrase, open the job and translate. Screenshots appear in the editor context / Live Preview.

AI Translation (optional)

Use AI Translation in the panel footer to send strings without new screenshots, run Phrase Language AI pre-translation, and duplicate compositions with translated text in After Effects.

Import translations back into After Effects

  1. When translation is complete in Phrase, select the same composition(s) and language(s).
  2. Click Import Selected (or equivalent). The panel creates new comps named [comp name]_[language].
  3. Optional: Open in Phrase opens the current project in the browser (cloud.memsource.com).

Disconnect or change TMS

  • Disconnect clears Phrase tokens on the server for this computer.
  • ← Change TMS during onboarding lets you switch between Crowdin and Phrase.
  • Refresh reloads projects and languages from Phrase.

Crowdin — quick reference

Choose Crowdin or Crowdin Enterprise at connect time. Workflow is similar: connect → project → send compositions with screenshots → import translations. Crowdin uses WYSIWYG screenshot tagging; Phrase uses Job Preview Package. See Technical documentation for API differences.

Troubleshooting

SymptomWhat to try
Panel blank or no network Enable Allow Scripts to Write Files and Access Network in AE prefs; restart AE.
OAuth / login failed Complete Allow in the browser tab opened by the panel; do not only open Phrase dashboard. Click Connect again.
Login timed out Finish authorization within ~45 seconds; retry Connect. Check firewall/proxy for login.cultextensions.com.
Phrase account not allowed Browser shows “account not allowed” — ask your Cult admin to add your Phrase email to the workspace allowlist in Cult Studio.
Not connected / HTTP 401 Disconnect in the panel, then Phrase → OK → Allow again. Confirm Cult license is active.
Phrase session ended Same as above — reconnect from the panel. Server uses TMS OAuth; reconnect when Phrase invalidates the access token (see TECHNICAL.html §2).
License bound to another device Each seat allows one computer. Reset device binding in Cult Studio, or contact support.
Project list empty (Phrase) Confirm projects exist at cloud.memsource.com for the same account. Click Refresh or re-select Phrase and OK.
Publish / finalize failed Run export in order: strings → screenshots → publish. If it persists, see server error in the alert and Technical docs — Error handling (§5).
Import has no translations Ensure Phrase jobs are complete for that file/language. Refresh project; retry import.
Wrong or missing screenshots Add Snapshot markers on layers with motion; re-export. Phrase uses quarter-res timeline captures by default for speed.
Windows curl / upload errors Ensure Windows 10+ with built-in curl. Check temp disk space. Retry export.

For HTTP status codes, API paths, and server-side errors, see TECHNICAL.html.

Data security (summary)

  • Text and screenshots are sent over HTTPS to login.cultextensions.com, then to your TMS (Phrase or Crowdin).
  • Screenshots are staged on the Cult server only until publish, then removed.
  • OAuth tokens are stored on the Cult server, not in the After Effects project or panel file.
  • Each Cult seat is bound to one computer (device binding).
  • Translations remain in your TMS project; Cult Connector does not archive customer translation content long-term.
